# Documentation language

Project and engineering documentation is written in English: README, goals, plans, handoffs, developer guides, release notes, contribution guidance and writing-skill instructions.

The owner explicitly requested a Thai user manual with application screenshots. The approved exception is docs/manual/th, including its Markdown, offline HTML and image captions. Link to that guide from English pages using an English label.

Thai application UI, runtime dictionaries/profiles, document input/output and meaningful language regression fixtures remain supported. English writing guidance can instruct the model to draft in formal Thai.

Preserve licenses and attribution. Historical Thai glyph examples in English upstream prose use Unicode identifiers.

Documentation-language checks must exclude the Thai manual and original private documents under gitignored docsStorage. This prose policy does not translate organization templates or test fixtures.
