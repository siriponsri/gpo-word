# Brand

GPO Word uses an independent document-and-review mark in navy and emerald. The folded-page outline represents structured documents; the integrated check represents author review.

- Primary ink: #102338.
- Accent: #00A58E.
- Neutral page background: #F6F8FA.
- Master raster: assets/brand/gpo-word-logo.png, with transparency.
- Repository wordmark: GPO Word, set as text beside or below the mark.

The mark is original AI-assisted artwork prepared for this project. Its source and distribution terms are recorded in ATTRIBUTION.md. It does not reproduce the official Government Pharmaceutical Organization emblem.

Keep clear space around the mark. Do not place text or document content inside it. For dark surfaces, use an appropriate contrasting treatment and verify the actual result.

The README uses the new mark. Existing platform icon files are retained upstream assets until a developer deliberately integrates and verifies GPO-specific desktop icons. Do not claim the app icon has changed merely because the README changed.
