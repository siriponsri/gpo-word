# Internal memorandum writing patterns

Use the chosen template for the header. Draft the body separately. Names, numbers, dates, recipients and signatories in an example are not defaults for a new document.

Select an opening that fits the situation:
- A prior matter: identify the earlier actor, event and date, then connect it to the present request.
- A new matter: state the issuing unit's intention or concrete reason.
- A document transmittal: identify the supplied documents and their intended use.

The next paragraph states the action or consideration requested, the responsible party and the supporting facts actually available.

For work involving several units, distinguish the sender's own actions from those the recipient should perform or help follow up. Choose precise wording for action, consideration, notification or follow-up according to actual responsibility.

Do not replace every requested action with a generic request for assistance. If the user wants a polite cooperation request, use suitable formal Thai while still identifying the task and expected outcome.

Choose a closing appropriate to information, consideration or action. Never assert that approval, a document number or an attachment already exists if it has not been supplied. Use visible placeholders for missing details.

These patterns were abstracted from writing examples. They are guidance, not an approved organization policy or a certification of format.
